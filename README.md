# Signal — Feedback Prioritizer

**Signal** is an interactive front-end prototype exploring how product teams can collect customer feedback, organize it, and decide what to work on next.

Designed as a small, transparent AI-assisted build. The project uses **React, TypeScript, and Vite**, with sample data and browser-only storage. There is no backend, user account system, or live AI integration. The *suggested focus* is based on simple priority and vote rules, not a machine-learning model.

## Features

- Create new feedback items with category and priority
- Search and filter customer feedback
- Update each item's status and vote count
- Review dynamically calculated summaries and category breakdowns
- Keep changes in browser local storage
- Responsive layout for desktop and mobile

## Run locally

Install Node.js, then in the project folder:

```bash
npm install
npm run dev
```

Open the local URL displayed in the terminal.

## Build

```bash
npm run build
```

## Why I built this

As a product designer, I wanted to explore how feedback can be transformed into clear, actionable priorities. This is a learning project focused on designing an intuitive interface and using AI coding assistance to translate design ideas into a functional front-end prototype.

**Note:** Feedback examples are fictional. No customer data or production integrations are used.
